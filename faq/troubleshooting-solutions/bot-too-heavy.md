# Bot too heavy

If the upload fails because the file is too big, the problem is almost always **what's inside the `.zip`**: it carries files Discloud doesn't need to receive.

***

## 🗑️ Leave out what doesn't need to be uploaded

{% hint style="warning" %}
#### **Dependency folders**

Folders like `node_modules`, `venv` or `.venv` are usually the biggest part of a project. Don't upload them: your dependencies are listed in your language's dependency file (for example, `package.json` or `requirements.txt`).
{% endhint %}

{% hint style="warning" %}
#### **Build output**

If you use the `BUILD` command in your [`discloud.config`](../../configurations/discloud.config/), Discloud runs the build during deployment. In that case, don't upload the folder generated by your local build.
{% endhint %}

{% hint style="warning" %}
#### **Large media files**

Large videos, images and audio files make the `.zip` heavy. Keep them in an external storage service and load them by URL.
{% endhint %}

{% hint style="warning" %}
#### **Version control and cache files**

Folders like `.git` and `__pycache__` aren't needed to run the application.
{% endhint %}

{% hint style="info" %}
Use a [`.discloudignore`](../../configurations/.discloudignore.md) file so these files are left out automatically. See also [**How to compress?**](../general-questions/how-to-compress.md).
{% endhint %}

***

## 🔀 Use another upload method

When you upload with the **Discord Bot**, the `.zip` is a message attachment, so it also has to fit within **Discord's attachment limit**. For bigger projects, prefer one of these methods:

* 🖥️ [**Dashboard**](../../how-to-host-using/dashboard.md)
* ⌨️ [**CLI**](../../how-to-host-using/cli.md)
* 🟦 [**VS Code Extension**](../../how-to-host-using/visual-studio-code.md)
