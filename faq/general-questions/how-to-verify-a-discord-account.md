# Como verificar uma conta do Discord?

Para usar o **Bot da Discloud** e gerenciar suas aplicações pelo Discord, você precisa **verificar a sua conta** no servidor Discord da Discloud. Só depois disso você tem acesso ao canal de comandos.

***

## ✅ Verificando a sua conta

{% stepper %}
{% step %}
Entre no [**Servidor Discord da Discloud**](https://discord.discloudbot.com/).
{% endstep %}

{% step %}
Siga as instruções do canal de verificação.
{% endstep %}

{% step %}
Depois de concluir a verificação, você recebe o cargo **`Verified pt-br`**.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Com a conta verificada, você passa a ter acesso ao canal [**`#🔌・commands`**](https://discord.com/channels/584490943034425391/1051126795883261962), onde pode usar os comandos do bot para gerenciar suas aplicações.
{% endhint %}
