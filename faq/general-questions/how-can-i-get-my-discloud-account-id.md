# Como obter o ID da minha conta Discloud?

### 🪪 O que é o ID da Conta Discloud?

O **ID da Conta Discloud** é um identificador numérico único que a Discloud atribui à sua conta no momento do cadastro. Diferente do Token da API, o ID da conta é uma **informação pública**, ou seja, você pode compartilhá-lo sem risco.

***

### 📍 Como Encontrar o ID da Sua Conta

{% stepper %}
{% step %}
Abra o Dashboard: [https://discloud.com/dashboard](https://discloud.com/dashboard)
{% endstep %}

{% step %}
No canto inferior direito, clique no **seu perfil** para abrir o menu de usuário.
{% endstep %}

{% step %}
No menu que aparecer, clique em **My account**.
{% endstep %}

{% step %}
Na página de informações da conta, o seu **ID** aparece logo abaixo do seu avatar.

<figure><img src="../../.gitbook/assets/Dashboard-Account-ID.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
