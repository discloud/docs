# Perguntas Gerais

## 🧾 Propósito

Esta seção agrupa respostas curtas e autocontidas às perguntas mais frequentes da plataforma—para que você possa se desbloquear sem abrir um ticket. Para depuração mais profunda ou problemas da plataforma, veja [Onde Obter Ajuda](../where-to-get-help.md).

{% hint style="info" %}
Se sua pergunta envolve interrupções, discrepâncias de cobrança ou preocupações de segurança, escale via modmail (ticket direto da equipe) em vez de confiar nestas páginas.
{% endhint %}
