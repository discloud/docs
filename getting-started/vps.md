# VPS

## 🖥️ Summary

A VPS is cloud Linux with **root** over SSH. It does **not** use bots/sites plan RAM: you buy a **quota** of RAM + SSD (add-on), then create one or more machines that consume that pool.

| Step           | Where                                                             |
| -------------- | ----------------------------------------------------------------- |
| Buy quota      | Dashboard → **VPS** → Buy resources (also Subscription → Add-ons) |
| Create machine | Dashboard → **VPS** → New VPS                                     |
| Access         | SSH with IP, user `root` and password from the overview           |

{% hint style="info" %}
Current minimums per machine / quota: **4 GB** RAM and **50 GB** SSD. Full details on vCPU, status, recreate, canceling quota and comparison with apps are on the product page.
{% endhint %}

{% hint style="danger" %}
Canceling VPS quota **destroys every machine** on the account.
{% endhint %}
