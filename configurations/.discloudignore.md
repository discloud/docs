# .discloudignore

## ❓ **What is `.discloudignore`?**

The `.discloudignore` file specifies files and directories to exclude when uploading your app to Discloud. Unlike `.gitignore`, it has a simpler syntax: **you list exact names of files/directories to ignore** (no wildcards like `*.log` or trailing slashes for folders).

📌 **Why Use `.discloudignore`?**\
✔ **Reduces upload size** – Avoids unnecessary files being sent.\
✔ **Speeds up deployments** – Less data means **faster processing**.\
✔ **Keeps deployments clean** – Prevents sensitive or unnecessary files from being included.

🔑 **Key Differences from `.gitignore`**\
&#xNAN;**• No trailing slashes** for directories (use `node_modules`, not `node_modules/`).\
\&#xNAN;**• No wildcards** – Specify exact filenames (e.g., use `error.log`, not `*.log`).\
\&#xNAN;**• No advanced patterns** – Only basic line-by-line exclusions are supported.

***

## 📂 **Placement of the File**

The `.discloudignore` file <mark style="color:yellow;">**must be in the**</mark> [<mark style="color:yellow;">**root**</mark> <mark style="color:yellow;">of your project</mark>](../faq/general-questions/what-is-the-root-of-the-project.md).

📌 **Example project structure:**

```
/my-project
 ├── src/             ❌ (ignored)
 ├── node_modules/    ❌ (ignored)
 ├── discloud/        ❌ (ignored)
 ├── config/          ❌ (ignored)
 ├── .discloudignore ✅
 ├── discloud.config
 ├── index.js
 └── package.json
```

***

## 📄 **General Example Usage**

Here is a **generic example** of what you may want to exclude in your projects:

{% code title=".discloudignore" %}
```ini
# Ignore directories
.git
.vscode
.idea
cache

# Ignore OS files
.DS_Store
Thumbs.db

# Ignore specific files
secrets.env
debug.log
```
{% endcode %}
