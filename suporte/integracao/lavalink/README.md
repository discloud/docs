# Lavalink

**Lavalink** é um programa autônomo, escrito em Java.&#x20;

É uma solução leve para reproduzir música de fontes como **YouTube** ou **Soundcloud**. Ao contrário das soluções de voz bruta, como **VoiceNext**, o **Lavalink** pode lidar com centenas de fluxos simultâneos e suporta fragmentação.

Você pode hospedar o seu próprio servidor **Lavalink** aqui na **DisCloud** e fazer integração com as seguintes linguagens.
